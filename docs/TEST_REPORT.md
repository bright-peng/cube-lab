## 核心测试

命令：`npm test`。运行环境：Node.js 22.16.0。

**37 项通过，0 失败。** 包括六个面的四次旋转恒等、18 个动作的逆操作与合法性、记号解析、右手四步重复六次复原、F 面方向的已知映射，以及单棱翻转、单角扭转、奇偶性错误的拒绝测试。

前三阶段模式数据库生成数量分别为 190,080、136,080、26,880；断言全部通过。每阶段公式还检查其是否保留上一阶段的成果。

使用固定随机种子生成 **200 组独立训练打乱状态**，每组 15–50 步，逐组调用求解器并回放验证，全部复原。该样本平均解法长度为 106.17 步，最大 145 步；这些是测试样本统计，不是任意输入的性能或步数保证。这里半圈按一步计算。

`npm run check` 的 JavaScript 语法检查通过。`npm run build` 成功输出单文件 HTML。本地 HTTP 服务通过直接请求验证入口、核心 JS、Worker 和 CSS 均返回 200 及相应 MIME 类型。

## 浏览器检查

**35 项通过。** 覆盖：

- 54 个平面色块与状态逐个匹配。
- 自定义公式播放，完整分层求解，前进/逆向回退与暂停。
- 七节配套案例逐节完整播放并复原。

测试观察到 Blob Worker 被创建。内部 `blob:` 资源请求不是互联网请求。

## 明确未验证的内容

构建环境的管理策略禁止浏览器导航到本地 HTTP、测试域名及 `file://` 页面。为遵守这一限制，浏览器测试使用 `page.set_content` 载入**与交付完全相同的单文件 HTML**，并关闭网络。

因此没有实测本机文件双击打开、真实来源下的原生 localStorage 跨刷新恢复、Safari/Firefox、物理触屏、GitHub 账号创建、GitHub Actions 远程执行或实际 Pages 发布。测试中的来源不允许 localStorage，页面按设计显示导出提示，而不是误报保存成功。

单元与随机测试提高可信度，但不构成对全部魔方状态和设备环境的形式化证明。后续正式对外发布仍应补做真实 Chrome/Safari/Firefox、Windows/macOS 和实际托管域名验收。

详细浏览器检查名称与限制见 `browser-report.json`；原始 Node 测试输出见 `unit-test-output.txt`。
