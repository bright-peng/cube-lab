怎么使用这些公式？

公式不是对任意状态都有效的魔法。先辨认目标块、摆放方向和当前阶段，再执行。练习按钮会载入一个与该公式匹配的案例；真实打乱请用「分层求解」，让引擎按当前状态生成适用公式。

本教程用“底层 → 中层 → 顶层”的分层路线。顶层借用 Sune、T-perm、U-perm 等常用公式；它不是完整 CFOP 速拧教程，也不追求最少步数。

从第一性原理，重新认识魔方。

把立体玩具拆成三个问题：状态是什么、转动如何改变状态、怎样到达目标。

01 / STATE

移动的是块，不是独立的颜色。

标准三阶魔方有 8 个角块、12 个棱块和 6 个中心块。角块上的三个颜色永远一起移动；棱块上的两个颜色也不能拆开。外层转动时，中心块定义各面的固定颜色。

8 corners + 12 edges + 6 centers

程序为 54 个贴纸分配唯一编号，保存它们占据的位置。旋转后颜色从同一份状态读取，三个视图不会各算各的。

02 / TRANSFORM

一次旋转，就是一次置换。

把所有贴纸的位置记作 S。执行 R 后，状态成为 R(S)。一次公式是多次置换的组合；逆公式按相反顺序，逐步执行逆操作。

R R R R = I   ·   R R′ = I

例如 R U R′ U′ 会先改变一部分位置，再有选择地撤回部分变化。这种结构帮助我们移动目标块，同时保留一部分已完成区域。

03 / SEARCH

这是状态图，不是流量网络。

你贴来的 flow network 文字讨论容量、流量和最大流。而魔方中，一个合法状态是一个节点，一次合法转动是一条边；目标是找到到达复原状态的一条路径。

scrambled state → moves → solved state

本项目对前三阶段构建模式数据库，并沿距离下降方向找路径；顶层阶段用保持前面成果的公式做广度优先搜索。公式作为一个搜索步骤时，不同公式实际手转步数不同，所以整体不保证最短解。

04 / PROJECTION

一个状态，三种观察方法。

3D 用透视投影呈现真实空间坐标；十字展开图用于查看六个面；交叠圆由三组各三个圆组成，分别对应左右、上下、前后三层。54 个彩色交点与 54 张贴纸一一对应。

one state → 3D / net / rings

每个圆经过 12 张贴纸。转动一个外层时，这 12 张贴纸沿圆移动三格，同时该面自身的 8 张贴纸转位。圆不是一个面：点选色点会高亮它所在的两条轨道，并与 3D 中的同一张贴纸联动。

2D / 联动视图

从第一步开始

先点「随机打乱」，再点「分层求解」。通过下一步、上一步和暂停，观察公式怎样让每个阶段完成。

R / R' / R2正对右面观察：顺时针 90° / 逆时针 90° / 180°。其他面同理。
拖动 / 双击拖动只改变观察视角，不重定义 U/R/F。双击可转动点中的面；按住 Shift 双击反转。
U R F D L B键盘按对应字母转面。Shift + 字母反向，空格播放/暂停，方向键左右逐步播放。
Ctrl / Cmd + Z撤销；再加 Shift 重做。输入公式时不会误触快捷键。

只支持标准三阶、外层转动。没有真实魔方摄像头识别或手工涂色输入。播放时面旋转先完成，再把状态提交给 2D 视图。
